# Production library

Shared, committed assets for Hybrid Film. Anything here is available to every film on every machine
as `library:<path>` (e.g. `library:athletes/athlete_m.glb`) and is listed by `hfilm library`.
Each folder has the script that rebuilds it from pinned, checksummed sources.

| folder | contents | source / licence |
|---|---|---|
| `athletes/` | `athlete_m.glb`, `athlete_f.glb` (athletic bodies with faces, universal skeleton), light/dark skin textures, hairstyles (`hair_buzzed`, `hair_simpleparted`, `hair_long`, `hair_buns`, `hair_buzzedfemale`), `hair_beard`, eyebrows | Quaternius *Universal Base Characters [Standard]*, CC0 1.0 — `athletes/build.mjs` |
| `motion/ual.motion.json` | 24 clips: idle, walk, jog, sprint, jumps, roll, falls, getting up, keeper throw, slide, nods, gestures | Quaternius *Universal Animation Library 1 + 2 [Standard]*, CC0 1.0 — `motion/build.mjs` |
| `motion/cmu-sports.motion.json` | 32 captured clips: 6 soccer kicks + left-foot mirrors (with contact times), jog/run/sprint cycles, backpedal, side-steps, dejected walk, 5 celebrations, high fives, pointing, waving, applause, shrug | CMU Graphics Lab Motion Capture Database (mocap.cs.cmu.edu), created with funding from NSF EIA-0196217. Free to use; do not resell the data — `motion/build.mjs` |

Kits are generated by the renderer (`web/athlete.js`), so they need no files; ready-made kits and
squads are in `src/athletes.mjs` (`KITS`, `squad`, `athlete`). Stadiums are generated in Unreal by
`ue/stadium.py` (`hfilm ue stadium`).

Formats:
- `*.motion.json` is `hfilm-motion@1`: per clip, per universal bone, the world-space rotation delta
  from the source's rest pose (int16 quaternions, base64), the source's rest bone directions, and the
  hips displacement in leg lengths. `web/motion.js` turns a clip into local rotations for any rig.
- Clip `meta`: `kind` (kick, celebration, gesture, reaction, locomotion), `foot` and `contact`
  (seconds) for kicks, `speed` (leg lengths per second) and `stride` for locomotion cycles.
